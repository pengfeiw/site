CAD 几何建模中的导数与积分：从曲线长度到曲面面积与实体体积 #

1. 为什么几何建模需要导数和积分 #

在学习 CAD 几何算法时，经常会遇到：

  • 曲线长度；
  • 曲面面积；
  • Solid 体积；
  • 曲线切线；
  • 曲面法线；
  • 曲率；
  • 最近点；
  • 曲线/曲面求交；
  • 质量、重心、惯性矩；
  • Tessellation。

这些问题背后大量使用了微积分。

对于几何建模，可以先建立一个非常直观的认识：

导数负责描述一个几何对象在局部是怎样变化的；积分负责把无数个局部的小量累加成一个整体。

可以简单记成：

导数
↓
局部

积分
↓
整体

例如：

Curve
  ↓ 导数
局部切线、速度
  ↓ 积分
整条 Curve 的长度

曲面也是一样：

Surface
  ↓ 偏导数
局部切向量
  ↓
局部面积
  ↓ 积分
整个 Surface 面积

2. 什么是导数 #

假设有一个函数：

y=f(x)y=f(x)y=f(x)

导数：

f′(x)f'(x)f′(x)

可以理解成：

当 xxx 发生一个非常小的变化时，yyy 变化得有多快。

数学定义：

f′(x)=lim⁡Δx→0f(x+Δx)−f(x)Δxf'(x) = \lim_{\Delta x\rightarrow0} \frac{f(x+\Delta x)-f(x)} {\Delta x}f′(x)=Δx→0lim​Δxf(x+Δx)−f(x)​

其中：

f(x + Δx) - f(x)
-----------------
        Δx

表示：

y 的变化量 / x 的变化量。

当 Δx\Delta xΔx 越来越小时，就得到这一点的瞬时变化率。

从几何上来说：

导数就是曲线在这一点的切线斜率。

3. CAD 中的参数曲线 #

CAD 中的 Curve 一般不是简单的：

y=f(x)y=f(x)y=f(x)

而通常使用参数曲线：

C(t)=(x(t),y(t),z(t))C(t) = (x(t),y(t),z(t))C(t)=(x(t),y(t),z(t))

例如：

t = 0.0 → P0
t = 0.1 → P1
t = 0.2 → P2
...

随着参数 ttt 发生变化，一个点沿着 Curve 运动。

对参数曲线求导：

C′(t)=(x′(t),y′(t),z′(t))C'(t) = (x'(t),y'(t),z'(t))C′(t)=(x′(t),y′(t),z′(t))

得到的不再是一个数字，而是一个向量。

这个向量表示：

Curve 在参数 ttt 处的瞬时运动方向以及运动速度。

因此：

C'(t)
↓
切向量

这就是 CAD Kernel 中常见的：

curve->D1(u, point, tangent);

这一类 API 背后的数学含义。

4. 一阶导数和二阶导数 #

参数曲线：

C(t)C(t)C(t)

一阶导数：

C′(t)C'(t)C′(t)

主要描述：

曲线往哪个方向走。

也就是切向量。

而二阶导数：

C′′(t)C''(t)C′′(t)

描述的是：

曲线的运动方向本身变化得有多快。

因此二阶导数与：

曲率
弯曲程度

密切相关。

可以粗略理解：

C(t)
↓
位置

C'(t)
↓
切线 / 速度

C''(t)
↓
切线变化 / 加速度 / 曲率

这也是为什么 B-Spline、Bezier 等几何 API 经常提供：

D0
D1
D2
D3

这样的求值接口。

5. 什么是积分 #

积分可以先理解成：

把无数个非常小的量加起来。

假设：

y=f(x)y=f(x)y=f(x)

希望计算从 aaa 到 bbb 的曲线下方面积。

把区间切成很多小段：

Δx\Delta xΔx

每个小长方形面积约为：

f(xi)Δxf(x_i)\Delta xf(xi​)Δx

所以：

A≈∑if(xi)ΔxA \approx \sum_i f(x_i)\Delta xA≈i∑​f(xi​)Δx

如果让：

Δx→0\Delta x\rightarrow0Δx→0

这些长方形越来越窄、数量越来越多，就得到：

A=∫abf(x),dxA= \int_a^b f(x),dxA=∫ab​f(x),dx

因此积分符号：

∫\int∫

可以先理解成：

不断累加。

6. dx、ds、dA、dV 是什么 #

积分公式里经常会看到：

dxdxdx

可以直观理解成：

x 方向上一个无限小的长度。

类似地：

ds → 一个无限小的曲线长度

dA → 一个无限小的面积

dV → 一个无限小的体积

于是：

∫ds\int ds∫ds

表示：

把所有小长度累加起来。

而：

∫dA\int dA∫dA

表示：

把所有小面积累加起来。

所以：

长度 = 小长度的累加
面积 = 小面积的累加
体积 = 小体积的累加

这是理解几何积分最重要的直觉。

例如：

这里表示：

所以：

L=5×1=5L=5\times1=5L=5×1=5

一般来说：

∫035,dt=5(3−0)=15\int_0^3 5,dt = 5(3-0) = 15∫03​5,dt=5(3−0)=15

这与我们后面计算曲线长度的思想完全一致。

8. 为什么曲线长度需要导数和积分 #

假设参数曲线：

C(t)=(x(t),y(t),z(t))C(t) = (x(t),y(t),z(t))C(t)=(x(t),y(t),z(t))

参数范围：

t∈[t0,t1]t\in[t_0,t_1]t∈[t0​,t1​]

希望计算真实曲线长度。

不能简单计算：

Distance(C(t0),C(t1))Distance(C(t_0),C(t_1))Distance(C(t0​),C(t1​))

因为这只是两个端点之间的直线距离。

例如：

       ********
    ***        ***
 A *              * B

真实长度：
沿着 ****

端点距离：
A ---------------- B

所以必须计算曲线本身的长度。

9. 从一个非常小的曲线段开始 #

假设参数变化了一个很小的：

dtdtdt

那么：

dx=x′(t)dtdx=x'(t)dtdx=x′(t)dt dy=y′(t)dtdy=y'(t)dtdy=y′(t)dt dz=z′(t)dtdz=z'(t)dtdz=z′(t)dt

这一小段 Curve 已经非常接近直线。

根据三维勾股定理：

ds=dx2+dy2+dz2ds = \sqrt{dx^2+dy^2+dz^2}ds=dx2+dy2+dz2​

代入：

ds=x′(t)2+y′(t)2+z′(t)2,dtds = \sqrt{ x'(t)^2+ y'(t)^2+ z'(t)^2 },dtds=x′(t)2+y′(t)2+z′(t)2​,dt

而：

C′(t)=(x′(t),y′(t),z′(t))C'(t) = (x'(t),y'(t),z'(t))C′(t)=(x′(t),y′(t),z′(t))

所以：

∣C′(t)∣=x′(t)2+y′(t)2+z′(t)2|C'(t)| = \sqrt{ x'(t)^2+ y'(t)^2+ z'(t)^2 }∣C′(t)∣=x′(t)2+y′(t)2+z′(t)2​

最终得到：

ds=∣C′(t)∣dt\boxed{ ds=|C'(t)|dt }ds=∣C′(t)∣dt​

它其实就是：

速度 × 一个非常小的时间 = 一个非常小的路程。

12. B-Spline 曲线长度怎么计算 #

对于 Line：

L=Distance(P0,P1)L=Distance(P_0,P_1)L=Distance(P0​,P1​)

可以直接得到解析结果。

对于圆弧：

L=RθL=R\thetaL=Rθ

也有解析公式。

但是对于复杂 B-Spline：

但这个积分通常很难得到简单的解析表达式。

于是 CAD Kernel 通常会采用：

13. 什么是数值积分 #

数值积分的思想仍然是：

采样，然后逼近积分结果。

例如：

L=∫01∣C′(t)∣dtL= \int_0^1|C'(t)|dtL=∫01​∣C′(t)∣dt

把参数区间切成：

0   0.1   0.2   0.3   ...   1
│    │     │     │           │
↓    ↓     ↓     ↓           ↓
计算 ||C'(t)||

然后近似累加：

L≈∑i∣C′(ti)∣ΔtL \approx \sum_i |C'(t_i)|\Delta tL≈i∑​∣C′(ti​)∣Δt

理论上采样越密，通常结果越精确。

实际 Geometry Kernel 往往会采用：

  • 梯形积分；
  • Simpson 积分；
  • Gaussian Quadrature，高斯积分；
  • Adaptive Integration，自适应积分。

其中 CAD 几何算法中比较常见的是高斯积分以及自适应积分。

14. 自适应积分和自适应 Tessellation 很相似 #

假设 Curve 某个区域变化非常平缓：

这和 CAD Tessellation 的：

↓

思想非常接近。

32. 面试中如何回答“怎么计算 Edge 长度” #

如果面试官问：

一个 BRep Edge 对应 B-Spline Curve，怎么计算它的长度？

可以回答：

Edge 会关联底层参数曲线以及它实际使用的参数区间 [u0,u1][u_0,u_1][u0​,u1​]。对于参数曲线 C(u)C(u)C(u)，一阶导数 C′(u)C'(u)C′(u) 表示曲线相对于参数的局部速度，因此微小弧长为：

ds=∣C′(u)∣duds=|C'(u)|duds=∣C′(u)∣du

整个 Edge 的长度就是：

L=∫u0u1∣C′(u)∣duL= \int_{u_0}^{u_1} |C'(u)|duL=∫u0​u1​​∣C′(u)∣du

Line、Circle 等简单解析曲线可以直接使用解析公式，而 B-Spline 等复杂曲线一般通过高斯积分、自适应数值积分等方法计算。

这已经是比较完整的几何算法回答。

33. 面试中如何回答“怎么计算 Surface 面积” #

可以回答：

对参数曲面 S(u,v)S(u,v)S(u,v)，分别计算两个参数方向的一阶偏导 SuS_uSu​ 和 SvS_vSv​。两者构成曲面的局部切向量，其叉积的模表示参数空间一个微小区域映射到三维后的面积缩放，因此：

dA=∣Su×Sv∣du,dvdA= |S_u\times S_v|du,dvdA=∣Su​×Sv​∣du,dv

再对 Face 对应的有效 UV 区域进行二重积分：

A=∬D∣Su×Sv∣du,dvA= \iint_D |S_u\times S_v|du,dvA=∬D​∣Su​×Sv​∣du,dv

对于 BRep Face，积分区域 DDD 还需要考虑 Outer Wire 和 Inner Wire 对应的边界。

34. 面试中如何回答“怎么计算 Solid 体积” #

可以回答：

从数学定义上，实体体积可以看成对内部所有微小体积 dVdVdV 做三重积分：

V=∭ΩdVV=\iiint_\Omega dVV=∭Ω​dV

但对于 BRep Solid，因为已经拥有闭合边界，几何 Kernel 可以利用散度定理把体积积分转换为对边界 Face 的曲面积分，再累加所有 Face 的贡献。因此不需要真正把 Solid 内部离散成大量体素。

这种回答比简单说：

调 VolumeProperties()。

更能体现对底层几何算法的理解。

36. 总结 #

对于 CAD 几何建模，导数和积分不应该只理解成数学公式。

最重要的是理解它们解决的问题。

导数 #

描述几何对象局部是如何变化的。

典型应用：

曲线切线
曲面切向量
曲面法线
曲率
连续性
最近点
投影
几何求交
Newton 迭代
Tessellation

积分 #

把无数个局部的小量累加成一个整体。

最重要的三个公式可以理解为：

L=∫ds\boxed{ L=\int ds }L=∫ds​

表示小长度累加成曲线长度。

A=∬dA\boxed{ A=\iint dA }A=∬dA​

表示小面积累加成曲面面积。

V=∭dV\boxed{ V=\iiint dV }V=∭dV​

表示小体积累加成实体体积。

而对于参数几何：

L=∫∣C′(t)∣dt\boxed{ L= \int |C'(t)|dt }L=∫∣C′(t)∣dt​

以及：

A=∬∣Su×Sv∣du,dv\boxed{ A= \iint |S_u\times S_v| du,dv }A=∬∣Su​×Sv​∣du,dv​

则把导数与积分真正联系起来。

可以最终浓缩成一句话：

导数负责研究几何的“局部”，积分负责把局部累加成“整体”。

这也是为什么从 Curve、Surface 到 BRep Solid，导数和积分会不断出现在 CAD 几何 Kernel 的长度、面积、体积、曲率、质量属性、求交、投影以及网格离散化算法中。
